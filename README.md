# My Projects Code

A personal archive of experimental code, AI prototypes, dashboards, and interface experiments.

## Current Contents

The repository currently contains standalone prototypes rather than one unified application, including:

- `ai_pentestV1.py` — Python AI pentesting prototype
- `ai_pentestV1.go` — Go version/prototype
- `home.html` — web interface prototype
- `dashboard-v10.1.html` — dashboard prototype
- `ollama-*.html` — Ollama-related dashboard and UI experiments

## Recommended Organization

```text
my-projects-code/
├── ai-pentest/          # AI pentesting experiments
├── ollama/              # Ollama UI and integration experiments
├── dashboards/          # General dashboard prototypes
├── web/                 # Standalone web experiments
├── archive/             # Superseded versions kept for reference
├── docs/                # Notes and project maps
└── README.md
```

The current files are historical prototypes. They should be moved into these categories only after checking dependencies between files.

## Important Versioning Rule

Avoid storing many unrelated versions in the repository root with names such as `v1`, `v2`, `v3`. For active projects, use Git commits/tags or dedicated project folders instead. Keep old versions in `archive/` when they are still useful for reference.
