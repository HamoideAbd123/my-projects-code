# My Projects Code

Personal archive of AI, cybersecurity, web, and server experiments.

## Organized Structure

```text
my-projects-code/
├── ai-pentest/     # AI-assisted pentesting and security experiments
├── ollama/         # Ollama dashboards and UI experiments
├── dashboards/     # General dashboard prototypes
├── server/         # Go server prototypes and iterations
├── web/            # Standalone web experiments
├── docs/           # Project documentation and maps
├── tests/          # Future test suites
├── archive/        # Reserved for intentionally archived work
└── README.md
```

## Categories

### `ai-pentest/`
Contains Python and Go security-testing prototypes, including AI-assisted testing and scanner experiments.

### `ollama/`
Contains the historical Ollama UI/dashboard iterations. Versioned prototypes are kept together so they can be compared without cluttering the repository root.

### `server/`
Contains Go server experiments and historical iterations.

### `dashboards/`
Contains general dashboard prototypes that are not specifically Ollama-related.

### `web/`
Contains standalone web experiments and small application prototypes.

## Versioning Policy

Do not create new `v1`, `v2`, `v3` files in the repository root. Keep active work in a logical project directory and use Git commits/tags for meaningful versions. Move obsolete experiments to `archive/` when they no longer need to remain active.

## Safety Note

Security-testing code in this repository should only be used against systems you own or are explicitly authorized to test.
